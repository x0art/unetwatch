## 4. Un-Collapse Operator Notes (Spec §5)

> **Applies only when Mode = `COLLAPSED` or `UC-B`.**  
> These are **not code changes** — the operator must add these fields at the Logstash / proxy ingestion layer.  
> Once the field appears in ES, re-run `/api/es/fields` to confirm the mode upgrade.

### 4.1 Cheapest: Upgrade to UC-B (UA Lens)

| Field to Add | Where | Notes |
|--------------|-------|-------|
| `user_agent` | Logstash / proxy | Single field. Un-collapses from `COLLAPSED` → `UC-B`. Enables UA-based session grouping (`ua+client_ip`). |

### 4.2 Upgrade to UC-A (Identity Lens)

| Field to Add | Where | Notes |
|--------------|-------|-------|
| `username` or `cs_username` | Proxy auth layer / Logstash | Durable identity (e.g., LDAP/AD username, SSO principal). Requires `user_agent` also present for full UC-A. |
| `session` or `cookie` | Proxy / Logstash | Session cookie value (e.g., `JSESSIONID`, `PHPSESSID`, OIDC session). Alternative to username. |

### 4.3 Policy-Class Enrichment (All Modes)

| Field to Add | Where | Purpose |
|--------------|-------|---------|
| `method` | Proxy / Logstash | HTTP method (`GET`, `POST`, etc.) — enables method-based policy breakdown. |
| `response_status` | Proxy / Logstash | HTTP status code (`200`, `403`, `500`) — enables status-class pivoting. |
| `bytes` / `response_bytes` | Proxy / Logstash | Response size — enables data-exfil risk scoring. |
| `action` / `rule` | Proxy / Logstash | Per-row proxy action (`block`, `allow`, `monitor`) or rule ID that triggered. Gives policy class **without re-matching** URLs against block patterns at read time. |

> **Note:** `duration_seconds` and `action` are already in the baseline six (confirmed in `query_builder.py:94-129` and `result_processor.py:85-99`). Adding `action`/`rule` at the proxy layer makes them available directly from ES, avoiding the server-side post-filter in `result_processor.py`.
