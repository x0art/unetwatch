# Issue Tracker

## Provider

GitHub Issues (via the `gh` CLI).

## Repository

`x0art/unetwatch` — https://github.com/x0art/unetwatch

## Workflow

- Skills like `to-tickets`, `triage`, and `to-spec` read from and write to GitHub Issues.
- Use `gh issue create`, `gh issue list`, `gh issue view`, etc.
- Labels: see `docs/agents/triage-labels.md` if the `triage` skill is installed.

## PRs as a request surface

Disabled by default. Flip this flag if you want external PRs in the triage queue.
